# Mohammadreza Qaderi · Portfolio

Senior Backend Engineer portfolio — terminal-inspired, developer-focused, dark theme.

**Stack:** React, Vite, Tailwind CSS.

**Assets in `public/`:** Place `profile.jpeg` (your photo) and `Mgh.pdf` (full CV) here; they are served at `/profile.jpeg` and `/Mgh.pdf`. For the “Short CV” button, add `ShortCV.pdf` to `public/` when you have it (otherwise the link will 404 until then).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build & deploy (GitHub Pages)

```bash
npm run build
```

Deploy the `dist/` folder to GitHub Pages (e.g. push to a `gh-pages` branch or use the `dist` folder as the Pages source in repo Settings).

For user/org site (`username.github.io`), set **Pages** source to the branch that contains the built files (e.g. deploy `dist` contents to `main` or use GitHub Actions to build and push to `gh-pages`).
